# Ferry Checkout App

A modern ferry checkout and tally application built with React, TypeScript, and Vite.  
Designed for fast, mobile-friendly fare calculations and streamlined checkout tracking.

## Features

- Ferry rate calculation
- Real-time tally tracking
- Mobile-friendly responsive UI
- Dark mode support
- Fast performance with Vite
- Built with reusable React components
- Type-safe development using TypeScript

## Tech Stack

- React
- TypeScript
- Vite
- React Router
- Tailwind CSS
- shadcn/ui
- Lucide React Icons
